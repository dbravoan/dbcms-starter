# Actualización

dbCMS 1.0.0 se instala en limpio. No hay ruta de actualización desde versiones
anteriores del producto.

Las webs consumidoras actualizan dependencias Composer de forma selectiva, por
paquete. Las subidas mayores futuras se gestionan siguiendo SemVer en cada
paquete; consulta [Publicación](PUBLICATION.md).

Para el día a día de una web (añadir o actualizar un módulo sin sincronizar todo
el catálogo), sigue [Crear proyectos](PROJECTS.md#5-actualizar-sin-sincronizar-todo).
